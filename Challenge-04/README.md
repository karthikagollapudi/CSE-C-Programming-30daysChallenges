This program takes expense amounts from the user and classifies them as Small, Medium, or Large using a loop and if-else conditions. It calculates the total and average expenses, ignores negative amounts, and stops when the user enters 0.
 Algorithm
1. Start the program.
2. Set all totals and counts to zero.
3. Enter an expense amount.
4. If the amount is 0, stop entering expenses.
5. If the amount is negative, print an error message.
6. If the amount is below 100, count it as Small.
7. If it is below 500, count it as Medium; otherwise, count it as Large.
8. Repeat until 0 is entered.
9. Display the total expenses and category-wise counts and totals.
10. Calculate the average if there are valid expenses.
11. Stop
