## CHALLENGE 02 - TRIPCALC
## To Find
Calculate the Fuel Required and Total Fuel Cost for a Road Trip.

## Problem Description

To calculate the fuel needed and total cost of the fuel for a road trip using distance, mileage of the vehicle and price of the fuel per litre.

## Aim

The aim is to use the variables, data types, input and output statements, arithmetic operators and the basic calculations in C.
## Algorithm

START

Read the distance of the trip

Read the mileage of the vehicle

Read the fuel price per litre

Calculate the fuel required

Fuel Required= Distance / Mileage

Calculate the total fuel cost

Total Cost= Fuel Required × Fuel Price

Display the fuel required and total fuel cost

STOP
