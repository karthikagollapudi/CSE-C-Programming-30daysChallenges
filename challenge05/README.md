Algorithm
1. Start the program and display the menu.
2. Ask the user to choose an option.
3. If the user chooses Linear Equation, find the value of x or display whether there is no solution or infinite solutions.
4. If the user chooses Factorial, check whether the number is between 0 and 12, then calculate its factorial.
5. If the user chooses Quadratic Equation, calculate the discriminant and display the roots based on its value.
6. If the user chooses Exit, stop the program. Otherwise, display an error for an invalid choice.
7. Repeat the menu until the user chooses Exit.
